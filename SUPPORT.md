# Getting help

- **A question or an idea**: open a [Discussion](https://github.com/maximeallanic/gnome-home-assistant/discussions).
- **Something is broken**: open an [issue](https://github.com/maximeallanic/gnome-home-assistant/issues/new/choose)
  with the bug report form.
- **A security problem**: do not open a public issue, see [SECURITY.md](SECURITY.md).

Before you ask, run `./verify.sh --online` and read [docs/troubleshooting.md](docs/troubleshooting.md): they answer
most problems. This is a volunteer project: answers are best effort, usually within a week.
